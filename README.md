# STANDARD PRO DAIRY POS — Releases

This public repository hosts Windows x64 installers and the update metadata used by STANDARD PRO DAIRY POS.

## Download

Get the latest installer from the [Releases page](https://github.com/Techiboy1/STANDARD-PRO-DAIRY-POS-RELEASES/releases/latest). The app checks this feed when it opens, downloads newer stable versions in the background, and asks before restarting to install one.

The release assets include the Windows setup file, `latest.yml`, and the installer block map required by the updater. The source code is kept in the private [STANDARD-PRO-DAIRY-POS repository](https://github.com/Techiboy1/STANDARD-PRO-DAIRY-POS).
